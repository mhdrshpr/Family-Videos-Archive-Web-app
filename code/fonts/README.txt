پوشه فونت‌های سامانه «خانواده من»:
می‌توانید فونت دلخواه خود (مثلا ایران‌سنس، وزیرمتن، یکان یا شبنم) را با نام‌های زیر در این پوشه قرار دهید:
- font.woff2
- font.woff
- font.ttf

سامانه به طور خودکار آن را شناسایی و برای تمامی بخش‌ها اعمال خواهد کرد.
در صورت عدم قرار دادن فونت، سامانه به طور خودکار از زیباترین فونت‌های فارسی سیستم‌عامل شما استفاده خواهد نمود.
